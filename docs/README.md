# CYPRESS_JS Project

## Running Cypress Tests

### Debug Mode
To run Cypress in debug mode, use the following command:

`npx cypress open`

This command will open the Cypress Test Runner, where you can run tests interactively and use developer tools for debugging.

### Headless Mode
To run Cypress in headless mode, use the following command:

`npx cypress run --headless`

This command will execute tests without opening the graphical interface, speeding up the testing process and allowing tests to run in environments where a GUI is not available.
