# Visual Studio Code Hotkeys

## General
- **Command Palette**: `Ctrl+Shift+P` or `F1`
- **Quick Open**: `Ctrl+P`

## Basic Editing
- **Cut Line (empty selection)**: `Ctrl+X`
- **Copy Line (empty selection)**: `Ctrl+C`
- **Paste**: `Ctrl+V`
- **Undo**: `Ctrl+Z`
- **Redo**: `Ctrl+Y`
- **Delete Line**: `Ctrl+Shift+K`
- **Move Line Up/Down**: `Alt+Up` / `Alt+Down`
- **Copy Line Up/Down**: `Shift+Alt+Up` / `Shift+Alt+Down`
- **Insert Line Below**: `Ctrl+Enter`
- **Insert Line Above**: `Ctrl+Shift+Enter`

## Navigation
- **Go to File**: `Ctrl+P`
- **Go to Symbol**: `Ctrl+Shift+O`
- **Go to Line**: `Ctrl+G`

## Search and Replace
- **Find**: `Ctrl+F`
- **Replace**: `Ctrl+H`
- **Find Next**: `F3`
- **Find Previous**: `Shift+F3`

## File Management
- **New File**: `Ctrl+N`
- **Open File**: `Ctrl+O`
- **Save**: `Ctrl+S`
- **Save As**: `Ctrl+Shift+S`
- **Close Editor**: `Ctrl+W`

## Terminal
- **Toggle Terminal**: `Ctrl+``
- **New Terminal**: `Ctrl+Shift+``

## View and Layout
- **Toggle Sidebar**: `Ctrl+B`
- **Toggle Full Screen**: `F11`
- **Zoom In/Out**: `Ctrl+=` / `Ctrl+-`

## Debugging
- **Start/Continue**: `F5`
- **Step Into**: `F11`
- **Step Over**: `F10`
- **Step Out**: `Shift+F11`
- **Toggle Breakpoint**: `F9`
- **Show Debug Console**: `Ctrl+Shift+Y`

## Source Control
- **Open Source Control**: `Ctrl+Shift+G`
- **Commit**: `Ctrl+Enter` (in the Source Control panel)
